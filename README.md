# MahetabO

**Version:** v1.1.0  
**Codename:** [0505] – Milestone updated on 05/05/2025

MahetabO is a visionary open-source eCommerce framework, inspired by the modular power of Magento but built from scratch for modern development practices. It aims to offer a fully customizable, scalable, and API-first commerce engine for developers and businesses alike.

---

## Features

- Modular architecture (inspired by Magento 2)
- REST and GraphQL API support
- Product, category, and inventory management
- Customer and admin user systems
- Cart and checkout flow with payment gateway integration
- Fully extendable module system
- Modern tech stack: Laravel + React JS  (planned)

---

## Getting Started

### Prerequisites

- PHP >= 8.1
- Composer
- MySQL or PostgreSQL
- Node.js & npm (for frontend)
- Redis (optional, for caching)
